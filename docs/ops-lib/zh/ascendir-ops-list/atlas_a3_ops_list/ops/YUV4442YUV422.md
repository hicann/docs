# YUV4442YUV422

```c
REG_OP(YUV4442YUV422)
    .INPUT(x, TensorType({DT_FLOAT16}))
    .OUTPUT(y, TensorType({DT_UINT8}))
    .OP_END_FACTORY_REG(YUV4442YUV422)
```

## Brief

YUV4442YUV422. Convert the image from yuv444 to yuv422.

## Inputs

- x: A 3D Tensor, dtype is float16, shape is (h, w, 4). The input yuv444
data. The format must be ND. 

## Outputs

- y: A 3D Tensor, dtype is uint8, shape is (h, w, 2). The output yuv422
data. The format must be ND. 

## Data Types

Note: The preceding prototypes are applicable to all chips, but the Data Types listed below are applicable only to the current chip.
### AI Core
- input0 x: float16
