# EL0022 Resource\_Error\_Insufficient\_SQCQ

## 错误信息

报错格式如下，占位符%s表示最大值：

```text
The number of SQ and CQ resources exceeds the upper limit. The maximum number of resources is %s.
```

报错示例如下：

```text
The number of SQ and CQ resources exceeds the upper limit. The maximum number of resources is 256.
```

## 解决方法

检查SQ和CQ申请和释放情况，不要超过资源上限。
