# 各产品型号功能支持情况

各产品型号上媒体数据处理各功能的支持度如下所示。其中，√表示支持，☓表示不支持。

    <!-- npu="950" id1 -->
- Ascend 950PR/Ascend 950DT上支持如下功能：
    - 媒体数据处理算子
    - DVPP图像/视频处理（媒体数据处理V2）

        各子功能的支持情况如下：VPC（**√**）、JPEGD（**√**）、JPEGE（**√**）、PNGD（**√**）、VDEC（☓）、VENC（☓）
    <!-- end id1 -->
