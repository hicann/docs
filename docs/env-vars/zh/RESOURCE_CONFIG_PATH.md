# RESOURCE\_CONFIG\_PATH

## 功能描述

用于设置配置异构资源描述信息文件的存储路径。

异构资源描述信息文件是JSON文件，包含单节点以及集群的描述信息，配置示例以及字段含义可参见《DataFlow开发》手册中的“附录 \> numa\_config.json配置”章节。

## 配置示例

```bash
export RESOURCE_CONFIG_PATH=/home/test/numa_config.json
```

## 使用约束

无
