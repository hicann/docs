# VPC处理时合理选择输出格式，降低内存申请，性能更优

## 背景说明

VPC图像处理功能支持输出YUV400格式（灰度图像），如果模型推理的输入图像是灰度图像，就直接使用VPC功能，无需再使用AIPP色域转换功能。

## 基本原理

直接使用VPC功能输出YUV400格式（灰度图像），省去使用AIPP色域转换功能，降低AI Core单元的负载，从硬件上提升性能。

## 使用说明

支持了YUV400格式，用户可直接将输出格式设置为YUV400，将内存大小设置为不小于“widthStride\*heightStride”的值，节省内存。

关于VPC功能的示例代码，请参见[VPC图像处理典型功能](DVPP_V1_VPC.md)。
