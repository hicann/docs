# 环境准备

基于CANN提供的接口开发、编译AI应用时，开发环境需具备如下软硬件基本要求：

- 硬件：一台X86服务器或ARM服务器。
- 软件：安装CANN Toolkit开发者套件包、CANN ops算子包。

若需运行该AI应用，运行环境还需具备如下软硬件基本要求：

- 硬件：必须有搭载昇腾AI处理器（通常也称为NPU）的产品。
- 软件：除了安装CANN Toolkit开发者套件包、CANN ops算子包，还需安装NPU固件包、NPU驱动包。

您可以单击[Link](https://www.hiascend.com/cann/download)根据引导在环境中安装软件包，详细安装说明请参见[《CANN软件安装》](https://hiascend.com/document/redirect/CannCommunityInstSoftware)。
