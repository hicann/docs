# AddNFusionPass

## 融合模式

当输入过多时，将输入按照如下规则进行分组，最后将每组之和进行相加。

N=62k+r，其中N为输入的个数，r为N整除62的余数。

- 规则一：当r=0时，分为k组，每组62个输入。
- 规则二：当r=1时，分为k组，k-1组为62个输入，最后一组为63个输入。
- 规则三：当2<=r<62时，分k+1组，k组为62个输入，最后一组为r个输入。

![](../figures/AddNFusionPass_1.png)

## 使用约束

- 所有输入需要满足AddN算子的要求。
- 该融合规则不可关闭。
