# 播音属性设置无效

## 适用场景

- 业务场景：播音
- 适用处理器：Atlas 200I/500 A2 推理产品
- 处理器形态：EP、RC

## 问题现象描述

在初始化播音相关参数时失败，并产生报错，返回错误码0xa0168003或者0xa016800c。

```bash
sample_comm_audio_start_ao: hi_mpi_ao_set_pub_attr(2) failed with 0xa0168003!
```

## 可能原因

播音涉及到的参数设置有误。

## 处理步骤

1. 检查Audio接口中各个输入参数（例如位宽、采样率、声道数等）是否在范围之内，若这些参数值不在取值范围内，需修改至有效范围内。
2. 再次执行播音命令。
