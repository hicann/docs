# EN0004 Not\_Supported

## 错误信息

报错格式如下，占位符%s表示报错原因：

```text
The operation is not supported. Reason: %s.
```

报错示例1如下：

```text
The operation is not supported. Reason: The interface hi_mpi_vdec_send_stream is not supported.
```

报错示例2如下：

```text
The operation is not supported. Reason: type:5 is not supported.
```

## 解决方法

接口或参数值不支持。
